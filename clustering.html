Section 03

Clustering

Using unsupervised clustering to look for natural structural groupings among films — without telling the algorithm what those groups should look like in advance.

(a) Overview

Clustering is an unsupervised learning technique that groups data points based on similarity, without using any predefined labels. The algorithm is only given the numeric features describing each item; it has no notion of a "correct" grouping and instead organizes the data based purely on how close or far points sit from each other in feature space.

There are two broad families of clustering approaches. Partitional clustering (most commonly k-means) divides the data into a fixed number of non-overlapping groups, k, chosen in advance, by iteratively assigning each point to its nearest cluster center and then recalculating those centers until the assignments stabilize. Hierarchical clustering instead builds a nested tree of groupings — starting with every point as its own cluster and successively merging the closest pairs (an "agglomerative" or bottom-up approach) until everything belongs to one cluster — with no need to decide k up front. The resulting tree, called a dendrogram, can be "cut" at different heights to produce different numbers of clusters after the fact.

Both approaches depend on a chosen distance metric to define "closeness." Common choices include Euclidean distance (straight-line distance, the default for k-means), Manhattan distance (sum of absolute coordinate differences), and cosine similarity/distance (which measures the angle between two feature vectors rather than their magnitude — useful when the overall scale of a data point matters less than its relative proportions). This project uses standard Euclidean distance for k-means and cosine distance for hierarchical clustering, as required.

Applied here, clustering is used purely for discovery — not prediction. The goal is to see whether films naturally fall into distinct structural "types" based on measurable attributes (runtime, genre count, release era, international reach, and audience engagement volume) with no rating-prediction target involved. If coherent clusters emerge, that's evidence these structural attributes carry real organizing signal; if they don't, that's an informative result too.

Both illustrations above use small synthetic examples purely to show how each method organizes data — not the movie dataset itself.

(b) Data Prep

Clustering requires only unlabeled, numeric data — no text fields, no row identifiers used as inputs, and no target/label column, since the entire point is to let the algorithm discover structure on its own rather than fit it to a known answer. Six numeric features were engineered from the cleaned movie dataset for this purpose: averageRating, numVotes (log-transformed, since raw vote counts are heavily right-skewed), runtimeMinutes, startYear, num_genres, and region_count (the number of distinct international regions a title was released in, from the EDA tab's akas data). All six were standardized (zero mean, unit variance) before clustering, since k-means and cosine-distance methods are both sensitive to the relative scale of input features.

This same prepared feature set is used for both the Clustering and PCA tabs, since both methods require the same kind of input.

Link to the data sample: data/unsupervised_features.csv (a derived, numeric-only dataset — original IMDb text fields and titles are not redistributed, consistent with IMDb's non-commercial data license).

# K-MEANS — partitional clustering, Euclidean distance (sklearn default)
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
from sklearn.metrics import silhouette_score

X_scaled = StandardScaler().fit_transform(X)   # X = the 6 numeric features

for k in [3, 4, 5]:
    km = KMeans(n_clusters=k, random_state=42, n_init=10).fit(X_scaled)
    print(k, silhouette_score(X_scaled, km.labels_))


# HIERARCHICAL CLUSTERING — cosine distance, average linkage
from scipy.cluster.hierarchy import dendrogram, linkage
from scipy.spatial.distance import pdist
from sklearn.cluster import AgglomerativeClustering

cosine_dist = pdist(X_scaled, metric="cosine")
Z = linkage(cosine_dist, method="average")
dendrogram(Z, truncate_mode="lastp", p=30)

hclust = AgglomerativeClustering(n_clusters=k, metric="cosine", linkage="average").fit(X_scaled)

(d) Results

Because cosine-distance hierarchical clustering requires a full pairwise distance matrix (which does not scale to tens of thousands of rows), both k-means and hierarchical clustering below were run on the same subsample of 1,000 movies — the same subsample for both algorithms, so the comparison between them is a fair, matched one.

Run on the full prepared feature set of 122,872 movies, with a 1,000-row subsample used specifically for k-means and hierarchical clustering comparison, as described above.

K-means at three different k values

Silhouette scores rose steadily as k increased across this initial comparison range: 0.195 at k=3, 0.212 at k=4, and 0.219 at k=5. None of these values is particularly high — silhouette scores run from -1 to 1, and values in the 0.2–0.3 range generally indicate real but modest cluster structure, rather than sharply separated groups. That's consistent with the nature of these features: runtime, vote count, release year, genre count, and international reach are all continuous, naturally varying quantities for real films, not attributes that would be expected to fall into a small number of tight, distinct camps.

Silhouette analysis — finding the "best" k

Searched across k=2 through k=10, the silhouette method identified k=2 as the best fit, with a score of 0.274 — higher than any of the k=3, 4, or 5 runs above. This result, combined with PCA's finding (right) that a single component captures over a third of the total variance, points toward the data having one dominant axis of structural variation that a 2-way split captures better than finer partitions — rather than several genuinely distinct film "types."

Hierarchical clustering — dendrogram

The dendrogram's largest-gap heuristic suggested k=5 — notably different from k-means's silhouette-preferred k=2. This divergence is informative rather than a contradiction: the two methods use different distance metrics (Euclidean for k-means vs. cosine for hierarchical clustering) and different criteria for choosing k (average silhouette across all points vs. the largest single jump in merge distance). Cosine distance in particular measures the angle between feature vectors rather than their absolute separation, so it can carve out more, finer-grained groups from the same data than a magnitude-based method does.

Hierarchical clusters, visualized — comparison to k-means

Comparing the two methods at the same, matched k (k=2), the Adjusted Rand Index between their cluster assignments came out to 0.504. ARI ranges from roughly -1 to 1, where 0 means no better than random agreement and 1 means identical labelings — 0.50 sits in the middle, indicating the two methods agree on the data's broad shape more often than not, but assign a meaningful share of movies to different sides of the split. Combined with hclust's own preference for k=5 rather than k=2, the overall picture is that k-means and hierarchical clustering see a similar underlying continuum in this data, but diverge on exactly how finely to carve it up — neither method finds hard, unambiguous clusters, which is the more informative finding than either k value in isolation.

(e) Conclusions

Across 122,872 movies described by six structural attributes, clustering found some organization but not sharply separated film "types." Silhouette scores stayed modest throughout (0.195 at k=3 up to a best of 0.274 at k=2), and the two clustering methods disagreed on how finely to divide the data: k-means with silhouette analysis favored a simple two-way split, while the cosine-distance dendrogram suggested five groups. At a matched k=2, the two methods agreed on roughly half of the structure (Adjusted Rand Index 0.504), which is a meaningful but far from unanimous overlap.

For the project's central question, this is a useful negative-leaning result. Runtime, genre count, release year, vote volume, international reach, and average rating do not cleanly sort films into distinct camps; they vary along a continuum. That fits the Introduction's framing that a film's reception depends on a tangle of overlapping factors rather than a few discrete categories, and it suggests that any relationship between structure and rating is more likely to be gradual and multi-factor than a matter of "which type of film is this." It also means clustering labels alone would be a weak basis for later predictive work, which makes the continuous, component-based view from PCA a natural companion analysis.
