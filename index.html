Predicting IMDb Ratings

Can a film's rating be estimated before audiences ever weigh in? This project pulls title, crew, and audience data from the IMDb developer API and tests several models against each other to find out.

What this project does

We collect structured movie data — genre, runtime, cast, release year, budget signals, and existing vote counts — through the IMDb API, then compare a handful of machine learning models on how well they can predict a title's IMDb rating. The goal isn't just accuracy: it's understanding which features actually move the needle on how a film is received.
