Section 05

Naïve Bayes

Predicting whether a film lands in the Low, Medium, or High rating tier from its structural attributes, using a probabilistic classifier.

(a) Overview

Naïve Bayes (NB) is a family of supervised classification algorithms built on Bayes' theorem. Given the features describing an item, NB calculates the probability that the item belongs to each possible class and predicts the class with the highest probability. Bayes' theorem expresses that calculation as the prior probability of the class (how common it is overall) multiplied by the likelihood of seeing these particular features within that class:

P(class | features)  ∝  P(class) × P(feature₁ | class) × P(feature₂ | class) × … × P(featureₙ | class)

The word "naïve" refers to one simplifying assumption: given the class, every feature is treated as independent of every other. That is rarely literally true (a film's runtime and genre count are related, for example), but the assumption collapses an otherwise intractable joint probability into a simple product of one-feature probabilities. The result is a model that trains in a single pass over the data, needs relatively little data to produce stable estimates, scales to very many features, and often classifies well even when the independence assumption is only roughly satisfied. NB is widely used for spam filtering, document and sentiment classification, medical diagnosis support, and any setting where fast, lightweight probabilistic predictions are valuable.

Multinomial Naïve Bayes

Multinomial NB is the standard version, designed for features that represent counts or frequencies, such as how many times each word appears in a document. For each class it estimates how much of the total "count mass" each feature accounts for, using additive (Laplace) smoothing so that a feature never seen in a class during training does not force that class's probability to zero:

P(featureᵢ | class)  =  (count of featureᵢ in class + α)  /  (total count in class + α × number of features)

Because it works with counts, Multinomial NB requires non-negative feature values. It is the version used as the primary model in this project, with each numeric feature rescaled to the 0 to 1 range so that all values are non-negative and comparable in size.

Bernoulli Naïve Bayes

Bernoulli NB is designed for binary features, each recording only whether something is present (1) or absent (0). Unlike Multinomial NB, which ignores a feature that is absent, Bernoulli NB explicitly models absence as evidence too: a film not being a Horror title counts toward the class probabilities just as being one does. It is a natural fit for short documents and yes/no indicators. Here it is applied to the genre indicator flags, the franchise flag, and the numeric features converted to "above or below the training-set median."

(b) Data Prep

Labeled data

Supervised learning requires labeled data: every example must come with the correct answer so that the model has something to learn from and be scored against. Only labeled data can be used for supervised methods. The label here is the film's rating tier, created by splitting the average IMDb rating at its 33rd and 67th percentiles into three equally sized classes: Low, Medium, and High. Equal class sizes mean that guessing is right about a third of the time, which makes accuracy easy to interpret. The rating itself is then removed from the inputs, so the model must predict the tier from structure alone.

The inputs are numeric only, as scikit-learn requires: log-transformed vote count, runtime, release year, number of genres, number of international regions, a 0/1 franchise flag (from the title-pattern heuristic), and twelve 0/1 indicator columns for the most common genres.

Training and testing sets

The labeled data was randomly divided into a training set (80%), used to build the model, and a testing set (20%), used only to measure how well the finished model performs. The split was stratified, meaning each set preserves the same Low / Medium / High proportions as the whole, and it was done by film, so each film appears in exactly one set.

The two sets must be disjoint (share no films). A model evaluated on films it already saw during training is being quizzed on its own answer key: it can score well by memorizing rather than by learning patterns that carry over to new films. Keeping the testing set completely unseen is what makes the accuracy figure an honest estimate of performance on films the model has never encountered. Disjointness was verified in code rather than assumed, and any scaling or median thresholds were calculated from the training set alone and then applied to the testing set.

Links: data/train_set.csv · data/test_set.csv

Results: Label cutoffs: Low = rating up to 5.40, Medium = above 5.40 up to 6.50, High = above 6.50. The three classes hold 42,193 (Low), 41,080 (Medium), and 39,599 (High) films, 122,872 in total. The training set contains 98,297 films and the testing set 24,575, with zero films in common. Because Low is the slightly larger class, always guessing "Low" would be right 34.3% of the time, which is the baseline used below.

Reading: Multinomial NB classified 50.4% of the 24,575 test films correctly (12,392 films), about 16 percentage points above the 34.3% baseline. Per class, 55.4% of Low films, 45.7% of Medium films, and 50.0% of High films were placed correctly. The mistakes are mostly near misses: a Low film was sent to Medium 33.1% of the time but to High only 11.5% of the time, and a High film went to Medium 35.3% of the time but to Low only 14.7%. Medium is the hardest tier (precision 0.402, recall 0.457), which is expected for a class that sits between the two extremes, and its errors spill almost evenly to both sides (27.5% to Low, 26.7% to High).

Model comparison

Reading: All three variants beat the baseline clearly, but the required Multinomial version was the weakest: 0.504, compared with 0.528 for Bernoulli and 0.531 for Gaussian. The Bernoulli and Gaussian results are only 0.3 percentage points apart, too close to call a real difference on a test set of this size. A plausible explanation, not tested here, is that Multinomial NB treats rescaled values such as runtime and release year as if they were counts and ignores a genre flag that is 0, while Bernoulli NB counts a missing genre as evidence and Gaussian NB models the continuous values directly.

(e) Conclusions

Results: Structure alone carries real but limited signal about how audiences rate a film. Trained on 98,297 films and tested on 24,575 it had never seen, Naïve Bayes assigned the correct rating tier about 50% of the time (Multinomial 50.4%, Bernoulli 52.8%, Gaussian 53.1%), against 34.3% for always guessing the most common tier. That is roughly a 1.5-fold improvement, far too large to be chance. It also means about half of all films still land in the wrong tier. Runtime, release year, genre mix, international reach, franchise status, and vote volume explain part of why a film is rated as it is, but not most of it. The model is better at separating weak films from strong ones than at pinpointing a tier. Confusing a Low film for a High one, or the reverse, happened for only 13.1% of those films. Of the 7,125 films predicted High, just 13.6% were actually Low, and of the 8,103 predicted Low, just 14.4% were actually High. Most errors involve the Medium tier, which is the hardest to identify (precision 0.402) because it borders both extremes. For a coarse screening question, such as which films are more likely to be well or poorly received, this is useful. For naming a film's exact tier it is not reliable. The variant matters less than the data. The three versions finished within about 3 percentage points of each other, and the two best were nearly tied, which suggests the ceiling here is set by the information in the features rather than by the choice of Naïve Bayes variant. Two caveats apply. First, Naïve Bayes assumes the features are independent given the class, yet vote count and international reach are clearly related, so some evidence is counted twice. Second, vote count is measured after release and reflects audience engagement as much as the film's structure, so part of the signal may come from popularity rather than from how a film is built. These results do not show which features the model relied on most, and the Decision Trees tab examines that directly.
